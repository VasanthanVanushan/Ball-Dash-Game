# 🎮 Ball Dash Game

Ball Dash Game is a fast-paced endless runner built with Unity where you control a rolling ball, dodge obstacles, collect coins, and chase high scores.

---

## 🚀 Features

- Smooth physics-based movement  
- Coin collection system  
- Distance-based scoring  
- High score saving using PlayerPrefs  
- Extra life system using coins  
- Pause, Game Over & Menu UI  
- Background music and sound effects  
- Infinite ground system  
- Random obstacle & coin spawning  

---

## 🕹️ Controls

- Move Left → A / Left Arrow  
- Move Right → D / Right Arrow  
- Jump → Spacebar  
- Pause → UI Button  

---

## 🧠 Core Systems

### Player Movement
- Forward acceleration with speed control  
- Lateral movement with boundary limits  
- Jump system with ground detection  
- Collision handling with obstacles  

### Coin System
- Collect coins during gameplay  
- Tracks current coins  
- Saves total coins using PlayerPrefs  

### Score System
- Score increases based on distance traveled  
- Real-time UI updates  

### High Score System
- Saves highest score using PlayerPrefs  
- Displays best score in menu  

### Game State System
- Playing  
- Pause  
- Extra Life  
- Game Over  
- Handles UI switching and time control  

### Audio System
- Background music  
- Sound effects (coin, collision, menu)  
- Persistent across scenes  

### World Generation
- Infinite ground system  
- Random obstacle spawning  
- Random coin spawning  
- Automatic cleanup of objects  

### Camera System
- Smooth follow player with offset  

---

## 💾 Data Saving

Uses PlayerPrefs for:
- Total Coins  
- High Score
